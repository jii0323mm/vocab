# 單字本

記下不會的英文單字或片語，自動補上 KK 音標、詞性、中文意思、詞形變化和例句，
用 8 格間歇式記憶法複習。可加到手機桌面，多人各自登入，手機電腦同步。

網址：https://jii0323mm.github.io/vocab/

## 架構

- 前端：這個 repo（GitHub Pages），`index.html` 單檔
- 後台：Google Apps Script 網頁應用程式「單字本後台」
- 資料：Google 試算表「單字本後台」
  - `Users`：帳號（密碼加鹽雜湊）
  - `Log`：所有操作紀錄
  - 每個使用者一個分頁，一列一個單字
- 查字：Gemini，金鑰放在 Apps Script 的指令碼屬性 `GEMINI_KEY`，不在這個 repo

## 複習規則

8 格：1 天、3 天、7 天、14 天、1 個月、3 個月、半年、1 年。
新字放第 1 格；答對往後一格，答錯往前一格；第 8 格答對就畢業。

## 改後台

改 Apps Script 後要「部署 → 管理部署作業 → 編輯 → 版本選新版本 → 部署」，
網址不變，前端不用動。
